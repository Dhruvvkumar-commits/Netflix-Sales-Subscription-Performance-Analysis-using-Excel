# Requirements

## Software

-   Microsoft Excel 2019 or later
-   Microsoft Excel 365 is recommended.

## Project File

``` text
Netflix_Sales_Dashboard(1).xlsx
```

## Excel Features Used

-   Pivot Tables
-   Pivot Charts
-   Slicers
-   Excel formulas
-   KPI calculations
-   Data visualization
-   Interactive dashboard components

## Dataset

The underlying dataset is available in the `Netflix_Sales_Data`
worksheet.

## Setup

1.  Install Microsoft Excel.
2.  Open `Netflix_Sales_Dashboard(1).xlsx`.
3.  Enable editing if required.
4.  Open the **Dashboard** sheet.
5.  Use slicers and filters to explore the dashboard.

## Skills Required

Basic knowledge of Excel, Pivot Tables, charts, slicers, formulas, and
business analytics.

## Note

No Python packages are required because this project is built entirely
in Microsoft Excel.
