# Netflix Sales Dashboard

## Project Overview

The **Netflix Sales Dashboard** is an interactive Microsoft Excel
dashboard designed to analyze Netflix sales and subscription
performance. It uses KPIs, charts, Pivot Tables, and slicers to present
business insights in an easy-to-understand format.

## Objectives

-   Analyze revenue trends over time.
-   Compare revenue across countries and regions.
-   Understand subscription type performance.
-   Track quarterly growth.
-   Analyze active users by region.
-   Compare new subscriptions with cancellations.
-   Analyze watch-hour performance.
-   Present key business KPIs through an interactive dashboard.

## Analysis Included

-   Revenue Trend By Year
-   Revenue By Country
-   Subscription Type Analysis
-   Quaterly Growth Analysis
-   Top Region By Active Users
-   New vs Cancellation
-   Watch Hour Analysis
-   KPI Analysis
-   Interactive Dashboard

## Tools Used

-   Microsoft Excel
-   Pivot Tables
-   Pivot Charts
-   Slicers
-   Excel formulas
-   KPI analysis
-   Data visualization

1.  Open `Netflix_Sales_Dashboard(1).xlsx` in Microsoft Excel.

4.  Explore the supporting analysis sheets for detailed insights.
